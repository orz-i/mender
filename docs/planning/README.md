## 纠偏后的执行顺序

先完成本轮主台账／状态页／一致性检查；之后优先回到原 **S4-10**，让已经实现的 Admin 后端形成用户可操作流程，再补 S4-09／S4-11，并按 S4-13／14 留下端到端证据。S4-07／08、S4-15～18 的缺口仍在原台账，不因优先做界面被取消或标成通过。
