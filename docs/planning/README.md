# Mender 实施计划

产品按六阶段推进：范围与技术验证 → 工程基础 → 执行与计量 → 能力接入与分发 → 商业与运营 → Beta 验收。

- [分阶段实施与验收计划](../design/02_Mender_分阶段实施与验收计划.md)：阶段目标、依赖、验收门禁及回退条件。
- [Excel 任务台账](Mender_实施任务与验收台账.xlsx)：任务、需求、测试、风险、ADR、甘特图和角色容量。
- [结构化台账](project-data.json)：92 项任务、40 项需求、48 项测试及相关治理记录。
- [当前工程基线](../engineering/initialization-report.md)：已建立的工程能力与待实现范围。

20 周计划从正式启动周 W1 起算；团队配置、工作量与关键决策在 G0 评审确认。任务状态以验收证据为准。

## 下一阶段

1. 明确首发范围、用户流程、统一语言和上下文所有权。
2. 验证 HTTP、MCP、远程 Agent 接入，以及预算预留与任务受理的原子事务。
3. 完成测试矩阵、威胁模型、负责人和工作量评审，形成 G0 决议。
4. 建立数据库与依赖边界检查，推进身份、租户和目录的首条业务流程。

调整台账时同步相关需求、测试和验收条件；变更基线记录数量时同步文档检查脚本。
