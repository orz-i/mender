## 实际改动

修复 Console Vite 缺少认证代理，以及 Admin 固定回调落点未注册的问题。受限文件秘密加载放在 platform/configenv 和 bootstrap，不将 SQL、环境读取或部署决策加入领域模型。API／Worker／operator 的原角色／权限约束保持，DSN 与对应文件不能同时设置。

新增显式受控 provisioning：迁移、21 个独立能力角色、归属标签和已有密码一致性验证。不存在默认管理员、预设秘密、伪造会话或自动发布；真实用户仍通过原 operator 绑定 issuer／sub 和成员权限。

新增固定 Linux/amd64 制品构建、scratch 非特权 API/Worker 镜像、Nginx 双域 TLS、数据库 verify-full 私有 CA、持久卷、角色最小挂载和只读文件系统。生产 preflight 使用独立公钥验签，核对实际镜像与每个制品字节，检查 Compose 和代理配置漂移。容器／卷归属不匹配即拒绝接管。

新增显式备份、停机后 release 切换及历史配置留存。切换不重设密码、不降迁移、不重建卷；DB 镜像升级不由此偷偷执行。Worker 默认控制模式，供应商执行仍需真实数据和受审出口配置。

## 真实验证

额外覆盖错签、公钥不可信、Compose 镜像替换、备份读取、运行中拒绝切换、停机切换后持久身份与秘密保持、nonce 错误和退出失效。该测试使用协议模拟 IdP，不是外部 IdP 认证；浏览器只在测试 context 中接受本地证书，API／数据库没有关闭 TLS。
