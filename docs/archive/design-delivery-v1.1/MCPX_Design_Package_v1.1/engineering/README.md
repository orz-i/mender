# MCPX 工程治理模板 / v1.1

本目录是治理规则、上下文清单与实施模板，不是已完成的工程脚手架，不包含真实 pnpm 锁或业务 CI。`architecture-policy.yaml` 当前仅是机器可读政策，没有连接 Go／TS 扫描器；不能仅凭文件存在声称已强制执行规则。

`toolchain.versions.template.json` 中 null 字段必须在 G0 替换为已验证的精确版本与真实证据。版本未确认前，不生成会被误用的假锁文件。`pnpm-workspace.yaml.example` 是目标路径示例；Go 仍使用 go.mod／go.sum。

按 G07 在 S1 实现工具链校验、Go／TS 依赖图、跨域边界、生成代码漂移和例外到期检查，并用 T41–T48 的负向样例验证。业务 CI 选择具体工具后固定版本；不依赖字符串 grep 证明所有 SQL 或间接依赖合规。

文档是 G00–G10，执行任务仍在 WBS；工程治理表跟踪规则，不重复计算人日。模板不含真实凭据、用户账号或虚构批准记录。
