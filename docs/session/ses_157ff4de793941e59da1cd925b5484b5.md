## 关键设计决定

- Preserve DDD/Clean Architecture ownership: Catalog, Distribution, Connections and Commerce own their plan data; admission consumes public ports and continues using the existing atomic UoW.
- Keep runtime reader, admission writer and cancellation writer as separate restricted PostgreSQL roles; admission writer cannot read plan source tables and runtime reader cannot read connection credential_version_ref or quota amount columns.
- Do not let clients select immutable ToolVersion IDs, PriceVersion IDs, budget IDs or budget period IDs; these are authoritative server plan facts.
- Do not claim supplier outcome before execution exists; StartRun response reports queued and reserved only.
