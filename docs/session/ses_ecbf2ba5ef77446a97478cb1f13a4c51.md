## 关键设计决定

- 切片1使用 catalog.tool_version_management 作为 workspace-scoped draft/published/retired 管理事实，runtime catalog.tool_versions 继续承载 callable published facts。
- 已发布 ToolVersion 核心内容由数据库 trigger 阻止原地修改；状态可进入 retired。
- Catalog manager DB role 与 browser-session/connection/admission/settlement role 分离，不授予 identity/execution、connection secret、budget limit/usage 或 published catalog mutation 权限。
- 新增 catalog:read（所有 active membership）与 catalog:manage（owner/admin/developer）；viewer 不可管理。
- Catalog manager 没有 lifecycle state 列直写、Connection secret/mutation、Budget amount/mutation、execution/identity authority；只通过受约束函数执行 publish/retire。
- Console management HTTP mutation 强制 Browser mutation authentication/CSRF，JSON 严格 unknown-field validation；micro amount 与 revision 输出 string。
- Publisher/Admin approval workflow 仍不在本阶段实现。
